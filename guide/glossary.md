# Working vocabulary

| Term | Meaning in this guide |
|---|---|
| Common operating picture | A shared, dated view of the situation with source context and known gaps |
| EOC | Emergency Operations Center; a coordination setting, not merely a dashboard |
| Sitrep | Situation report: a concise, dated assessment with actions and next update |
| Spatial epidemiology | Examination of health patterns in place and population, with attention to measurement and inference |
| Numerator | The counted events included in a stated definition and period |
| Denominator | The population or exposure base used to interpret a numerator |
| Report-date curve | Counts organized by when reports arrived; distinct from symptom-onset timing |
| Completeness | Received submissions as a fraction of expected submissions |
| Missing | Unknown or unreceived; distinct from an observed zero |
| Choropleth | Areas filled according to a numerical value, with a documented legend |
| GeoJSON | Geographic features and properties encoded as JSON; positions use longitude before latitude |
| Ecological inference | Drawing conclusions across levels, such as from area summaries to individual risk |
| Provenance | Where a value came from, when it was acquired and how it was transformed |
| Sandbox fixture | A deterministic sample illustrating an API contract |
| Pyodide | Python compiled for execution in a WebAssembly browser environment |
| CORS | Browser-enforced rules governing which sites may read an HTTP response |
| Jupyter Book | The narrative publication containing chapters and rendered outputs |
| JupyterLite | A browser-hosted notebook environment with browser-local execution and storage |
| Sensitivity analysis | Changing assumptions and examining how conclusions move |

Definitions are working descriptions for these exercises. For public-health methods, consult the [CDC Field Epidemiology Manual](https://www.cdc.gov/field-epi-manual/php/chapters/index.html); for coordination, consult the [WHO EOC framework](https://www.who.int/publications/i/item/framework-for-a-public-health-emergency-operations-centre).
